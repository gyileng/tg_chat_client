TG Chat Client 第一版测试包

1. 解压整个目录，双击 TGChatClient.exe；不要单独移动 exe。
2. 首次启动填写 API ID、API Hash 与代理。支持 SOCKS5 和 HTTP。
   后续修改代理端口：点击“连接设置”，修改端口后保存，全部账号会重新连接；无需删除账号。
   也可通过“设置 → 连接设置”或 Ctrl+, 打开；支持 Tab 选择按钮后按空格。
   发送、登录或账号操作未结束时会提示等待或关闭登录窗口；模拟模式不使用连接设置。
3. 添加账号，输入 +国家代码手机号、验证码；需要时输入两步验证密码。
4. 选择账号和已加入的群，管理短句后即可手动发送。
5. 右键账号可退出登录或移除账号，操作前需确认。退出保留草稿和统计，再次使用需重新登录。
   移除先退出，再删除该账号的本地会话、草稿、常用群、缓存和发送统计，不注销 Telegram 账号。
   退出失败时保留数据，请检查连接后重试；发送或登录期间不可操作。
6. 主窗口右上角 × 隐藏到右下角托盘，账号继续在线，已提交消息继续发送。
   单击或双击托盘图标，或右键“显示主窗口”，恢复聊天和草稿；最小化仍在底部任务栏。
   完全退出请右键托盘图标选择“退出”，或使用主窗口“程序 → 退出”。
   完全退出保存草稿并断开连接，不退出 Telegram 登录；未完成发送不自动重发。
   首次隐藏会提示恢复与退出方法；没有系统托盘时，× 正常退出。

Alt+1…9：选择前九个账号；短句不再使用 Ctrl+数字快捷键。
点击短句在光标处插入，有选中文字时替换选中文字；编辑后手动发送。
管理短句可设置每条的缩写（字母、数字、下划线，不区分大小写）。
添加或编辑时拒绝重复及前缀冲突，例如 wz 与 wzd 不能共存。
默认输入完整的 ;nh 或 ；nh 立即替换为配置的正文，无需空格；再按 Enter 发送。
前缀默认 ;，可在管理短句中改成一个或多个非空白符号，所有账号共用。
旧短句保留内容，请自行补填缩写；空缩写仍可点击。空格正常输入。
旧缩写若互为前缀，将暂停这些缩写的自动替换并提示修改，点击插入仍可用。
中文输入法候选状态下，完整“符号＋缩写”立即替换，无需切英文或按空格；未匹配的拼音正常选词。
粘贴或加载草稿不会自动展开；展开可一次撤销。
悬停可查看完整内容；拖动分隔线可调整面板宽度。
Enter：发送；Shift+Enter：换行。快捷键仅在本窗口前台生效。
双击消息或右键“引用回复”；快捷短句也使用当前引用。
所有媒体仅显示 [图片]、[贴纸]、[视频]、[音频]、[文件] 等占位，保留附带文字；不下载预览。
每个聊天缓存最近 500 条及最多 500 条历史浏览消息，最多缓存 10 个聊天；可分页加载更早消息。
历史浏览期间新消息不挤掉当前位置，点击“回到底部”切回最近消息。
已淘汰聊天重新打开会加载最近消息；草稿、引用和统计不受影响。
托盘隐藏或最小化时暂停聊天绘制与周期计数查询，账号继续在线，恢复时同步。
旧版图片缓存不再读取，也不自动删除。
向上浏览暂停自动滚动，点击“回到底部”查看新消息；当前聊天发送成功后自动回到底部。

计数表示通过本工具成功发送的条数，不代表群内认可的有效条数。
每日按北京时间零点划分。发送失败不自动重发；结果不确定时先查看群消息。

程序无需安装 Python。配置、独立会话与统计保存在：
%LOCALAPPDATA%\TGChatClient\real
请勿分享这个目录：含私有配置、登录会话和草稿。
更新程序时退出旧版，将新便携包解压至新目录，数据会继续保留。

体验模拟模式：在程序目录打开终端，运行 TGChatClient.exe --mock
模拟模式不连接 Telegram，数据与真实账号分开。

反馈问题请提供 Windows 版本、操作步骤、界面错误和必要的脱敏截图。
日志在上述数据目录的 logs 中；发送前请自行检查是否包含私密内容。
禁止上传会话文件、数据库、验证码、密码和 API Hash。
