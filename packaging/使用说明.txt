TG Chat Client 第一版测试包

1. 解压整个目录，双击 TGChatClient.exe；不要单独移动 exe。
2. 首次启动填写 API ID、API Hash 与代理。支持 SOCKS5 和 HTTP。
3. 添加账号，输入 +国家代码手机号、验证码；需要时输入两步验证密码。
4. 选择账号和已加入的群，管理短句后即可手动发送。

Ctrl+1…5：选择账号；Alt+1…9：直接发送对应短句。
Enter：发送；Shift+Enter：换行。快捷键仅在本窗口前台生效。
双击消息或右键“引用回复”；快捷短句也使用当前引用。
向上浏览暂停自动滚动，点击“回到底部”查看新消息。

计数表示通过本工具成功发送的条数，不代表群内认可的有效条数。
每日按北京时间零点划分。发送失败不自动重发；结果不确定时先查看群消息。

程序无需安装 Python。配置、独立会话与统计保存在：
%LOCALAPPDATA%\TGChatClient\real
请勿分享这个目录：含私有配置、登录会话和草稿。
更新程序时退出旧版，将新便携包解压至新目录，数据会继续保留。

体验模拟模式：在程序目录打开终端，运行 TGChatClient.exe --mock
模拟模式不连接 Telegram，数据与真实账号分开。

反馈问题请提供 Windows 版本、操作步骤、界面错误和必要的脱敏截图。
日志在上述数据目录的 logs 中；发送前请自行检查是否包含私密内容。
禁止上传会话文件、数据库、验证码、密码和 API Hash。
